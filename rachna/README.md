# Rachna — Formatter & Converter

Paste or drop a JSON, YAML, or CSV file → auto-detect format → pretty-print, validate, and show line-specific errors. Convert between the three formats.

**How it works:** Uses the browser's native `JSON.parse`/`JSON.stringify` for JSON, js-yaml (via CDN) for YAML, and a simple inline parser for CSV. All processing is local — no uploads.

**Live URL:** `https://prayog.pages.dev/rachna/`
