# Sankshep — Image Compressor

Drop an image, adjust quality and dimensions, preview the before/after size, and download. Browser-based compression using Canvas API — no uploads.

**How it works:** Draws the image onto an HTML Canvas at the chosen quality and dimensions, then exports as JPEG, WebP, or PNG. All processing is local.

**Live URL:** `https://prayog.pages.dev/sankshep/`
