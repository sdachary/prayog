# Tulna — Text Diff

Compare two texts side-by-side with word-level diff highlighting. Paste or type in both panes, click diff, and see additions and deletions highlighted.

**How it works:** Uses a longest-common-subsequence (LCS) algorithm to compute the minimal edit difference between the two texts. All processing is local — no uploads.

**Live URL:** `https://prayog.pages.dev/tulna/`
