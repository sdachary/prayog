PRAYOG//TOOLS
standalone browser utilities
SANDESH
Local network file transfer via WebRTC. Pair two devices with a 6-digit code and send files directly browser-to-browser.
DRISHTI
Read-only file scanner. Point it at a folder and it reports which files fail to open — nothing is modified.
SHUDDHI
Clean a compromised Windows PC. Step-by-step guide with a built-in scanner script — no tech knowledge needed.
BADHAI
Extract audio from video files in your browser. Drop a video, pick MP3/WAV/AAC/OGG, download. Nothing leaves your machine.
RACHNA
JSON / YAML / CSV formatter, validator & converter. Paste or drop a file, auto-detect, pretty-print, convert.
SANKET
QR code generator and camera scanner. Generate with text/URLs, download PNG/SVG, scan with your camera.
SANKSHEP
Image compressor and resizer. Drop an image, adjust quality and dimensions, preview size, download.
TULNA
Text diff tool. Compare two texts with side-by-side word-level diff highlighting. Paste, diff, copy.
ZARYA
External drive repair for Linux & macOS. Step-by-step guide to find corrupted files, repair filesystems, and check drive health.
GAMES
Snake & Ladder and Color Match — two quick browser games. Play against the CPU or test your luck.
All tools run entirely in your browser. Nothing is uploaded or stored remotely.
